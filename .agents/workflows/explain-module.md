---
description: Teach the current user the module they own, then quiz them (code-ownership rule)
---
1. Ask which module (e.g. apps/api/app/agent/graph.py, app/connectors/satellite.py, apps/web/components/FieldMap.tsx).
2. Explain it top-down in plain language: purpose, inputs, outputs, failure handling, callers.
3. Draw a small mermaid diagram of its control flow.
4. Ask 5 judge-style questions one at a time, wait for each answer, then correct it.
5. End with a 6-line cheat sheet the user can memorise.
